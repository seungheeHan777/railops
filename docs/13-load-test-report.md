# 부하 테스트 보고서

k6를 사용해 열차 조회, 좌석 조회, 좌석 HOLD, 결제 API를 부하 테스트합니다. 응답 시간, 실패율, DB 락 대기, 병목 지점을 기록합니다.

위 내용은 초기 목표입니다. 현재 k6 구현은 운행편 검색 전용이며 `infra/k6/search.js`에 있습니다. Docker 미설치로 k6 장시간 부하는 아직 실행하지 않았습니다.

2026-10-19 Node 읽기 스모크 실제 측정: 동일 PC, 동시 10개, 총 200회 운행편 검색, 실패 0, 전체 432ms, p50 11ms, p95 182ms, 최대 214ms. cold/warm 구간과 네트워크가 섞인 짧은 측정이며 production SLA나 k6 결과로 일반화하지 않습니다.

HOLD/결제/운행 취소/동일 열차 편성의 동시성은 PostgreSQL 통합 테스트로 검증했습니다. 장시간 부하와 DB 락 대기/병목 분석은 Docker 실행 환경 준비 후 진행합니다. 실행 절차는 `docs/38-local-and-container-runbook.md` 참고.
